# Mydes Browser 🌐✨

> An AI-powered, distraction-free modern Android web browser built with **Jetpack Compose**, **Chromium WebView**, **Room Database**, and dynamic on-the-fly website restyling (powered by **Gemini 3.8 / 3.5** and **NVIDIA NIM** models). Features the signature ergonomic **Plateau Notch** bottom navigation bar, live AI reasoning summarization, fluid tab switching, and pre-packaged offline visual themes.

## 🏗️ Architectural Overview

### 1. **User Interface (`app/src/main/java/com/example/ui`)**
- **Jetpack Compose UI**: Pure declarative UI using Material Design 3 guidelines.
- **`PlateauNotch.kt`**: Ergonomic bottom navigation pill tailored for one-handed operation. Houses back/forward navigation, address bar display, tab count badge, and options menu.
- **`WebContainer.kt`**: Chromium-based `WebView` hosting active web content with hardware acceleration, high refresh rate support (90Hz/120Hz), touch handling, and live CSS injection via `evaluateJavascript`.
- **`MorphingWebOverlay.kt`**: Visual overlay that renders live streaming reasoning thoughts, synthesis tokens, and diff reviews as the AI restyles the website.
- **`TabGridSheet.kt`**: Multi-tab switcher with thumbnail previews, incognito browsing, and instant tab creation/closure.

### 2. **AI Restyling Engine (`app/src/main/java/com/example/data/api`)**
- **Two-Pass Pipeline (`GeminiStylerService.kt`)**:
  - **Pass 1 (Synthesis)**: Analyzes page DOM structure, typography, contrast, and user prompt to synthesize an element-by-element design blueprint.
  - **Pass 2 (CSS Generation & Micro-RAG)**: Employs co-located element micro-RAG to generate pristine, targeted, non-breaking CSS stylesheets without prompt dilution.
- **Reasoning Modulator (`ReasoningModulatorConfig.kt`)**: Dynamically controls thinking level (`minimal`, `low`, `medium`, `high` for Gemini; `off`, `medium`, `full` for NVIDIA Nemotron).
- **Thought Summarization (`ThoughtSummarizer.kt`)**: Filters and summarizes raw reasoning tokens into clean, scannable conversational bullet points for the user.
- **Telemetry & Logs (`ApiRequestLogger.kt`)**: Automatically captures request payloads, tokens, latency, responses, and before/after screenshots for auditing and debugging.

### 3. **Data & Storage Layer (`app/src/main/java/com/example/data`)**
- **Room Database (`MydesDatabase.kt`, `MydesDao.kt`)**: SQLite persistence storing bookmarks, browsing history, domain brand color palettes, and saved AI CSS themes.
- **`PrepackageDataSeeder.kt`**: Bootstraps the app on first run by populating default themes, bookmarks, and configuration from `app/src/main/assets/` into device storage.
- **Repositories (`BrowserRepository.kt`, `WebsiteColorRepository.kt`)**: Provide clean reactive Kotlin `Flow` data access to the ViewModel.
